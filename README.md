# Smart Touch POS - Customer Items CSV Library

A lightweight, high-efficiency web hub for managing, validating, previewing, and 1-click downloading cleaned customer item CSV files for **Smart Touch POS**.

## Live Website & Direct Access
- **Main Portal:** https://ebrahimagaber.github.io/smart-pos-csv-library/
- **CSV Customer Library:** https://ebrahimagaber.github.io/smart-pos-csv-library/csv-library.html

## Features
- **Zero-Login Cashier Access:** Download cleaned item files directly on client cash registers without logging into personal email, WhatsApp, or cloud accounts.
- **Arabic UTF-8 with BOM Preservation:** Prevents Arabic character corruption in Excel and POS screens.
- **Live In-Browser Data Grid:** Search, preview, and inspect items before importing.
- **Offline Persistence:** IndexedDB storage keeps files stored safely and locally in the browser.
- **Standard POS Template:** Includes the official empty template for item imports.
